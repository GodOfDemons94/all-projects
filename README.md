# All Projects Repository

This repository contains a collection of data science, machine learning, and web development projects. Each project focuses on different aspects of data analysis, machine learning, and software development.

## Projects Overview

### Data Science & Machine Learning Projects
1. **IBM-DATA-SCIENCE-CAPSTONE-SPACEX**
   - A capstone project analyzing SpaceX launch data
   - Focuses on data analysis and visualization

2. **Project_Tweet_Classification**
   - Natural Language Processing project for tweet classification
   - Implements text classification techniques

3. **Project_Titanic**
   - Machine learning project analyzing the Titanic dataset
   - Focuses on survival prediction

4. **Project_Poisonous_Mushrooms**
   - Classification project for identifying poisonous mushrooms
   - Implements various classification algorithms

5. **Project_Housing_Price**
   - Regression analysis project for housing price prediction
   - Includes feature engineering and model evaluation

6. **Project_Diabetes**
   - Medical data analysis project focusing on diabetes prediction
   - Implements healthcare data analysis techniques

7. **Project_Clean_Dirty_Dish**
   - Image classification project for dish cleanliness
   - Uses computer vision techniques

### Python Projects
1. **Project_Python_WordGame**
   - A Python-based word game implementation
   - Focuses on Python programming fundamentals

### Web Development
1. **web_research_tool**
   - A web-based research tool
   - Implements web scraping and data analysis features
