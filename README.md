# Diabetes Risk Prediction Analysis

This project focuses on analyzing and predicting diabetes risk using machine learning techniques. The dataset contains various health-related features of individuals, including lifestyle factors, medical conditions, and demographic information.

## Dataset Overview

The dataset includes 236,378 samples with 22 features, including:
- Health indicators (BMI, Blood Pressure, Cholesterol)
- Lifestyle factors (Physical Activity, Smoking, Fruit consumption)
- Medical conditions (Heart Disease, Stroke)
- Demographic information (Age, Sex, Education, Income)

## Project Structure

- `assignment.ipynb`: Main Jupyter notebook containing the analysis
- `wine-dataset.csv`: Dataset file (Note: Despite the filename, this is a diabetes dataset)

## Features

- Data exploration and analysis
- Statistical summary of health indicators
- Machine learning model development
- Model evaluation and performance metrics

## Setup

1. Clone the repository:
```bash
git clone https://github.com/GodOfDemons94/all-projects.git
```

2. Install required packages:
```bash
pip install pandas numpy scikit-learn jupyter
```

3. Open the Jupyter notebook:
```bash
jupyter notebook assignment.ipynb
```
